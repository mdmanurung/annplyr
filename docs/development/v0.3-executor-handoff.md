## Frozen Plan

1. Verify baseline state and create the complete, mechanically tested v0.3 API
   contract before behavior changes.
2. Add the pinned ASV suite/manifest and capture c0f0735 baseline timing and
   peak-memory data before editing source behavior.
3. Centralize positional subsetting and ownership. Shape/order verbs default
   to independent `copy=True`; same-shape verbs use `inplace=False`; backed
   shape copies become independent in-memory subsets; same-shape backed writes
   fail closed. `inplace=True` always returns identical AnnData, including
   x-relocation and sorted add-count/tally.
4. Replace every label-based reconstruction path with zero-based integer
   positions so duplicate axis names remain correct.
5. Add `AnnplyrExpr` with exact/opaque dependencies, output width, cardinality,
   operator/method/namespace proxying, and `to_narwhals()`. Raw Narwhals is an
   isolated full-source opaque fallback. Preserve sequential mutation and only
   batch proven-independent assignments.
6. Add pandas, dense, CSR/CSC, backed-dense, backed-CSR/CSC adapters. Plan all
   projections and cumulative projected-cell charges before the first read.
   Add budgets to every matrix-reading evaluation/export API. Matrix `where()`
   is schema/dtype-only.
7. Add `GroupSpec` and one O(n + g) positional `GroupPlan` per operation.
   Groups are observed, first-seen, NA-inclusive, and nonempty. `.rows` is
   zero-based positions. All AnnData-returning grouped verbs return wrappers;
   grouped in-place returns identical `self`; select/transmute retain keys;
   rename updates keys; key mutation regroups after the call; pipe passes the
   wrapper; all joins run once globally and preserve/update grouping.
8. Optimize measured metadata/evaluation copies and virtual columns without
   weakening correctness or introducing mutable aliases.
9. Reach at least 85% branch-aware coverage, then configure
   `coverage.report.fail_under = 85`.
10. Run fixed full benchmarks. Each of matrix projection, grouped execution,
    and metadata evaluation needs one >=20% median-time or peak-RSS improvement;
    investigate every >10% primary regression outside noise. Write the compact
    report from raw samples and structural oracles.
11. Update version 0.3.0, changelog, citation date 2026-08-08, README, complete
    docs, migration guide, API reference, roadmap, bundled skill, affected
    notebook source cells, doctests, and CI. Never bulk execute notebooks.
12. Run every correctness, style, type, docs, benchmark, build, and strict
    package check. Compare a representative chained fixture structurally and
    report the fixture-level (not real-data) limitation.

Contract decisions that must not be reopened during implementation:

- Group selectors resolve once to existing metadata columns; computed,
  virtual-name, matrix, and empty grouping are rejected.
- `group_data()[".rows"]` uses zero-based integer positions.
- Grouped `transmute` retains keys; grouped `pipe` passes the wrapper.
- Non-inplace grouped calls return new wrappers; in-place calls return `self`.
- Right/full joins reject right-only axis records. Left/full preserve left
  order; inner/semi/anti preserve surviving left order; right follows right-key
  order and left order within key.
- `unmatched="error"` rejects unmatched left records; `drop` adds no restriction
  beyond natural join behavior.
- Backed `copy=True` shape verbs return independent in-memory AnnData.
- Matrix `where()` is schema/dtype-only.
- Budget charge is cumulative projected source cells used for evaluation/export;
  opaque inputs charge the full source; AnnData aligned storage copied only for
  ownership is outside this budget.
- Pandas aligned sources and sparse arrays remain supported.
- `group_by(add=...)` and `group_by(drop=...)` are deferred and removed from
  roadmap promises.
